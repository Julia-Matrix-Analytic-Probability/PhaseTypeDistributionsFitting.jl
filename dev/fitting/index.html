Fitting PH distributions

All estimators follow the Distributions.jl convention: dispatch on the target type and return a new distribution of that type. The target is either the general PHDist or one of the structured families (CoxianDist, HyperExponentialDist, HypoExponentialDist, ErlangPHDist), which constrains the fit to that family.

using PhaseTypeDistributions, PhaseTypeDistributionsFitting, Distributions, Random, Statistics
rng = MersenneTwister(2024)

truth = HyperExponentialDist([0.6, 0.4], [1.0, 0.25])   # mean 1.0, SCV > 1
data  = rand(rng, truth, 5000)
(empirical_mean = Statistics.mean(data), empirical_scv = var(data) / Statistics.mean(data)^2)
(empirical_mean = 2.20730281050221, empirical_scv = 1.9086808996382103)

General PH fit

Give the number of phases m for a random dense start, or an init distribution to start from (and to impose structure — see below).

phd = fit_mle(PHDist, data; m = 3)
(mean = mean(phd), scv = scv(phd))
(mean = 2.2073028105022128, scv = 1.9184984688532944)

Structured fits stay in-family

Each structured target returns its own type and keeps that family's structure throughout the fit:

cox = fit_mle(CoxianDist, data; m = 3)
hyp = fit_mle(HyperExponentialDist, data; m = 2)
hpo = fit_mle(HypoExponentialDist, data; m = 3)
erl = fit_mle(ErlangPHDist, data; m = 3)     # closed form: rate = m / mean(data)
typeof.((cox, hyp, hpo, erl))
(CoxianDist, HyperExponentialDist, HypoExponentialDist, ErlangPHDist)
mean.((cox, hyp, hpo, erl))
(2.2073028105022154, 2.2073028105022137, 2.207302810502214, 2.20730281050221)

Because PH distributions are not identifiable, compare fits by moments or CDF rather than by (α, T):

moments_isapprox(phd, hyp; rtol = 0.1), distribution_isapprox(phd, hyp; atol = 0.05)
(true, true)

Supplying an initial distribution

Any AbstractPHDist can be the starting point. Its sparsity pattern is preserved for the whole run (see The EM algorithm), so seeding a general PHDist fit with a structured distribution imposes that structure:

phd_cox = fit_mle(PHDist, data; init = CoxianDist([3.0, 2.0, 1.0], [0.3, 0.4]))
pattern(subgenerator(phd_cox))     # bidiagonal — the Coxian structure is locked
3×3 BitMatrix:
 1  1  0
 0  1  1
 0  0  1

The loop is controlled with maxiter, tol, verbose, and rng:

res = fit_mle(PHDist, data; m = 2, maxiter = 500, tol = 1e-9)
mean(res)
2.2073028105022066

The fit router

fit routes to fit_mle (method = :mle, the default) or fit_mm (method = :mm, method of moments):

f = fit(PHDist, data; method = :mle, m = 2)
mean(f)
2.2073028105022128

API

Distributions.fit_mle — Method
fit_mle(PHDist, data; m, init, maxiter=1000, tol=1e-7, verbose=false, rng)

Fit a general phase-type distribution to positive observations data by maximum likelihood using the EM algorithm (Asmussen–Nerman–Olsson). Provide the number of phases m for a dense random start, or an init distribution (any AbstractPHDist) — in which case the sparsity pattern of init is preserved, so explicit zeros stay zero throughout the fit.

Returns a PHDist whose α and T are FixedSparsity arrays carrying the preserved sparsity pattern. Phase-type distributions are not identifiable, so compare fits by moments or CDF (moments_isapprox, distribution_isapprox) rather than by (α, T) directly.

source
Distributions.fit_mle — Method
fit_mle(CoxianDist, data; m, init, maxiter=1000, tol=1e-7, verbose=false, rng)

Fit a Coxian PH distribution (α = e₁, bidiagonal T, exit possible at each phase). The Coxian structure is preserved by the EM and a CoxianDist is returned.

source
Distributions.fit_mle — Method
fit_mle(HyperExponentialDist, data; m, init, maxiter=1000, tol=1e-7, verbose=false, rng)

Fit a hyperexponential (mixture of m exponentials; diagonal T). Returns a HyperExponentialDist. Note SCV ≥ 1 is intrinsic to this family.

source
Distributions.fit_mle — Method
fit_mle(HypoExponentialDist, data; m, init, maxiter=1000, tol=1e-7, verbose=false, rng)

Fit a hypoexponential (convolution of m exponentials; α = e₁, absorption only from the last phase). Returns a HypoExponentialDist. Note SCV ≤ 1 is intrinsic.

source
Distributions.fit_mle — Method
fit_mle(ErlangPHDist, data; m)

Fit an Erlang (m phases of equal rate) by maximum likelihood. The shape m is fixed; the rate has the closed form λ̂ = m / mean(data), so no EM is required. Returns an ErlangPHDist.

source
StatsAPI.fit — Method
fit(T, data; method=:mle, kwargs...)

Convenience entry point routing to fit_mle (method=:mle, the default, maximum likelihood via EM) or fit_mm (method=:mm, method of moments). Extra keyword arguments are forwarded to the chosen estimator.

source
PhaseTypeDistributionsFitting.fit_mm — Function
fit_mm(T, data; …)

Moment-based fitting of a phase-type distribution. Not yet implemented — this is a placeholder for the moment-matching approach, which will land alongside the EM-based fit_mle. Use fit_mle in the meantime.
